# ⏱️ Premium Futuristic Digital Clock & Pomodoro Timer

A high-performance, aesthetically stunning, and interactive productivity application built using clean semantic HTML5, modern vanilla CSS3, and core JavaScript. This dashboard features an elegant spaceship cosmic design with advanced UI elements.

🔗 **[Click Here to View Live Project](https://github.io)**

---

## 🌟 Visual & Technical Features

- **Apple Watch Inspired Neon UI:** Built on a rich radial-gradient space theme (`#070214`) featuring bright neon accents for high contrast and modern readability.
- **Dual-Circle Progress Ring:** Uses high-precision SVG vector geometry to dynamically calculate the boundary line. It distinctively showcases the spent time over a hidden dark elapsed layer.
- **Dynamic Ambient Aura Glow:** Implements custom CSS `@keyframes` animations (`pulseGlow`) causing the center background matrix to smoothly breathe and oscillate while the timer runs.
- **Modular Configuration Overlay:** A beautifully integrated Glassmorphic Settings Modal triggered by a single gear mechanism (`⚙️`), cleaning clutter from the main control canvas.
- **Stabilized Typography:** Forced layout engine consistency using `font-variant-numeric: tabular-nums` to fully suppress any textual shaking during seconds synchronization.

---

## 🛠️ Tech Stack & Architecture

- **Structure:** Semantic HTML5
- **Style Mechanics:** Advanced CSS Layouts, Custom Layers (`z-index`), Soft Drop Shadows, Vector Tracing.
- **Logic Matrix:** Vanilla JavaScript (ES6+), Event Propagation Controls, Custom State Buffers, Mathematical Syncing.
